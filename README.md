# TapTalk AAC

TapTalk AAC is an early-stage iPad communication app concept for Australia. The planned experience is deliberately simple and centres on three main areas:

- **Talk** — tap AAC symbol cards to build and speak a message.
- **TapTalk** — type a message, speak it aloud, and save useful phrases.
- **QuickTalk** — speak saved phrases with one tap.

## Project status

This repository is the starting point for product design, legal and licensing research, and future iOS development. It does not yet contain a production application.

## Before development

The first release gates are:

1. Confirm the rights and licence for every AAC symbol collection.
2. Obtain advice on the app's intended purpose and TGA classification.
3. Define the privacy and data-storage design.
4. Confirm the commercial model and intended NDIS pathway.

## Planned technology

- iPadOS and SwiftUI
- Apple's on-device speech synthesis where suitable
- Local-first storage for phrases and settings
- Accessibility-first interaction and testing
